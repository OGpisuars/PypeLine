# Playtest notes

Notes from every playtest session (roadmap: "Keep PLAYTEST.md with notes from every session"). Newest first. Players new to Python are the most valuable testers: watch where they get stuck, and do not help unless they ask.

## How to run a session

1. Give the tester the latest [Windows build](https://github.com/OGpisuars/PypeLine/releases/tag/latest), or build from source.
2. Start from a fresh profile so they see the intro and chapter 1 (on Linux: `XDG_DATA_HOME=/tmp/pypeline-test cargo run --release`).
3. Ask them to think out loud. Note the time at each chapter and contract.
4. Afterwards, ask: What was confusing? What was fun? When did you want to stop?
